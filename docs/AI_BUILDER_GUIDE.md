# AI Course Builder - Quick Start Guide

## For Mentors: Creating Your First AI-Powered Course

### 🚀 Getting Started

**Access the AI Builder:**
1. Log in to your mentor account
2. Go to your Mentor Dashboard
3. Click the **"AI Course Builder"** button (purple gradient button in top-right)
   - OR click the prominent card if you have no content yet

### 📝 Step 1: Generate Ideas (2 minutes)

**What you'll do:**
- Describe what you want to teach in your own words
- Add target audience (optional)
- Add focus areas/topics (optional)

**Example prompts:**
```
"A comprehensive React course covering hooks, context, and performance optimization for developers with 1-2 years experience"

"A framework to help first-time entrepreneurs validate their startup ideas before building"

"An intermediate course on data visualization with Python using matplotlib and seaborn"
```

**What happens:**
- AI generates 3-10 course ideas
- Each idea includes:
  - Compelling title
  - Full description
  - Target audience
  - Problem it solves
  - Key topics

**Next:** Click on any idea card to use it (or regenerate for different options)

---

### 🎯 Step 2: Configure Your Draft (3 minutes)

**What you'll see:**
- Your selected idea pre-filled
- Editable fields for fine-tuning

**Required fields:**
- ✅ Course Title
- ✅ Content Type (Course or Framework)
- ✅ Level (Beginner, Intermediate, Advanced)
- ✅ Delivery Modes (check at least one)

**Optional but recommended:**
- Target Audience details
- Problem it solves (expanded)
- Topics to cover (outline)

**Pro tip:** The more detail you provide, the better the AI draft will be!

**Next:** Click **"Generate Full Draft With AI"**

**⏱️ Wait time:** 10-30 seconds for AI to create your complete course structure

---

### ✨ Step 3: Review & Refine (5 minutes)

**What you'll see:**
- Complete course draft with:
  - Polished title and description
  - Learning outcomes (bullet points)
  - Full module breakdown
  - Activities for each module
  - Resource suggestions
  - Estimated duration
  - Prerequisites

**You can:**

1. **Review Everything:**
   - Expand each module to see details
   - Check activities and resources
   - Verify learning outcomes

2. **Edit Manually:**
   - Click "Edit Details"
   - Change title, description, or price
   - Click "Save Changes"

3. **Ask AI to Refine:**
   - Type instructions like:
     - "Make it 4 weeks instead of 8"
     - "Add a module on advanced patterns"
     - "Make this more beginner-friendly"
     - "Add more practical exercises"
   - Click "Refine Draft"
   - See updated version in seconds

**You can refine multiple times!** Keep iterating until perfect.

**Next:** Click **"Save as Draft"** (green button)

---

### 🎉 Done! What Happens Next?

**Immediately:**
- Draft saved to your dashboard
- You're redirected to Mentor Dashboard
- Success notification appears

**From Your Dashboard:**
- Find your draft in the content section
- Click to edit further if needed
- Add media (images, videos)
- Set final pricing
- Click "Publish" when ready

## 💡 Tips for Best Results

### Writing Good Prompts (Step 1):

**Good ✅**
```
"A 6-week intensive JavaScript course for bootcamp graduates covering ES6+, async programming, and modern frameworks, with weekly projects"
```

**Too Vague ❌**
```
"JavaScript course"
```

### Providing Useful Topics (Step 2):

**Good ✅**
```
Module 1: ES6 basics (arrow functions, destructuring, spread)
Module 2: Promises and async/await
Module 3: React fundamentals
Module 4: State management with Redux
Module 5: Testing with Jest
Module 6: Deployment
```

**Too Basic ❌**
```
"JavaScript stuff, React, testing"
```

### Refining Effectively (Step 3):

**Specific ✅**
```
"Add a module about testing with real-world examples. Include unit tests, integration tests, and E2E tests."
```

**Too General ❌**
```
"Make it better"
```

## ❓ FAQs

**Q: Can I edit the AI-generated content?**
A: Yes! Everything is editable. Use AI as a starting point, then customize.

**Q: What if I don't like the generated ideas?**
A: Click "Regenerate" or go back and adjust your prompt.

**Q: Can I use this for frameworks, not just courses?**
A: Absolutely! Select "Framework" as the content type in Step 2.

**Q: Will this replace manual course creation?**
A: No, it's an optional helper. Manual creation is still available.

**Q: How many times can I refine?**
A: As many times as you want! Keep refining until perfect.

**Q: What happens to my draft after saving?**
A: It appears in your dashboard as a draft. Edit and publish when ready.

**Q: Can I come back and edit later?**
A: Yes! Drafts are saved. Edit anytime from your dashboard.

**Q: Does AI use my course for training?**
A: No. Your content is private and not used for AI training.

## 🎓 Best Practices

1. **Start Specific:** Better prompts = better ideas
2. **Review Carefully:** AI is smart but not perfect
3. **Refine Iteratively:** Make small changes, test, refine again
4. **Add Your Voice:** Personalize the AI-generated content
5. **Use Examples:** Real-world examples make courses better
6. **Test the Flow:** Walk through as if you're a student
7. **Price Thoughtfully:** Consider value, length, and audience
8. **Update Media:** Add images and videos after saving
