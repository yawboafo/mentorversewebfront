# MentorVerse Homepage Redesign
## Human-First Leadership Platform

---

## 🎯 Design Philosophy

**Core Principle:** Position MentorVerse as a HUMAN mentorship ecosystem where real leaders share lived experience—NOT as an AI-first platform.

### Brand Positioning
- **Primary Identity:** Leadership mentorship platform
- **Secondary Support:** AI-enhanced learning tools
- **Tone:** Inspirational, trustworthy, aspirational, human-first, global

### Key Message
> "Learn from people who've done it, lived it, achieved it."

## 🎨 Design System

### Color Palette

**Primary Gradients:**
- Hero: `from-amber-50 via-orange-50 to-rose-50`
- Dark mode: `from-amber-950/20 via-orange-950/20 to-rose-950/20`
- CTA gradient: `from-orange-600 via-rose-600 to-pink-600`
- Card gradients: orange-to-rose for action elements

**Accent Colors:**
- Orange: Leadership, energy
- Rose/Pink: Human warmth, connection
- Blue: Trust, clarity (for AI section)
- Green: Growth, success
- Purple: Community, wisdom
- Amber: Achievement, value

### Typography

**Headlines:**
- H1 (Hero): 7xl-8xl, bold, with gradient text on key phrase
- H2 (Sections): 3xl-4xl, bold
- H3 (Cards): xl-2xl, bold

**Body Copy:**
- Large: 18-20px for subheadlines
- Medium: 16px for descriptions
- Small: 14px for supporting text

**Font Style:**
- Clean, modern sans-serif (Inter or similar)
- High readability
- Professional but warm

### Visual Elements

**Icons:**
- Lucide React icon set
- Placed in colored circular backgrounds
- Consistent sizing (h-6 w-6 for small, h-8 w-8 for large)

**Cards:**
- Rounded corners (rounded-lg to rounded-2xl)
- Subtle shadows
- Hover effects (border color change)
- Consistent padding

**Badges:**
- Small, pill-shaped indicators
- Used for section labels ("Step 1", "Smart Support")
- Accent colors with icons

**Avatars:**
- Circular fallback avatars with initials
- Color-coded by role/person
- Consistent sizing (h-12 w-12 for testimonials, h-20 w-20 for mentors)

### Spacing & Layout

- Section padding: py-20 (mobile) to py-24 (desktop)
- Max-width container: max-w-7xl
- Grid layouts: 1 → 2 → 3 columns responsive
- Generous whitespace between sections

## 💡 Key Messaging Guidelines

### DO's:
✅ Emphasize "real people," "lived experience," "proven frameworks"
✅ Use human names, roles, and stories
✅ Position AI as support tool, not hero
✅ Highlight mentor credibility and diversity
✅ Focus on transformation through human wisdom
✅ Use warm, inspirational language
✅ Show social proof with testimonials

### DON'Ts:
❌ Lead with AI or tech features
❌ Use robotic or technical imagery
❌ Position AI as the main product
❌ Downplay human mentors
❌ Use generic "AI-powered" language in headlines
❌ Make AI more prominent than mentors
❌ Use cold, corporate tone

## 📱 Responsive Considerations

### Mobile (< 640px)
- Single column layouts
- Larger touch targets (min 44x44px)
- Simplified mentor grid (2 columns)
- Stacked CTAs
- Reduced text sizes appropriately

### Tablet (640-1024px)
- 2-column grids for value props
- Maintain visual hierarchy
- Adjust padding and spacing

### Desktop (> 1024px)
- Full 3-column grids
- Maximum visual impact
- Generous whitespace
- Larger typography
